Instruments

Every instrument is generated from its seed. Roll the dice, or paste a seed from the zyn demo or from Seedlathe. The same number sounds the same in all three.

notes, lower and upper octave
`

0–9
digits, in the numeric columns
− +
sign, in the filter column
Tab
next track
Del
clear the cell

On a phone there is no typing keyboard to offer, so use the pad under the grid. It does everything the keys do, and follows whichever column the cursor is in.

Columns

note
C-4 is middle C, OFF stops the track
inst
which instrument, from the Instruments tab
vel
how hard it is struck, 64 for unity
rel
scales this note's release, 25 for unity
cut
shifts this note's filter, in semitones
vol
level, 64 for unity

A track is monophonic: the next note cuts the one before it, which is what lets a held sound end where you say.
